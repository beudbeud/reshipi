FujiFilm Simulation Recipes

Subject: Fujifilm Film Simulation Recipes & More.
Last Update: 24.7.2026

In this page i am trying to list down some of Fujifilm Film Simulation Recipes that I fond on the Net or I create. I will try to add sample photos of that, but you can apply it and change it as you want to get the best shot for you. Most of the Recipes will start form what is available in the Canera then I may change some factors, or I will start from one on the FujiXweekly [Click to see].



Follow Me @ Instagram


Click-Here to see my Picture Profile and image sample for Sony system, my camera RX100vii.

Notes: 1. I am Using Fujifile X-T30ii with Fujinon XF 18-55mm and TTArtisan 27mm 2.8 lens. 2. If the Attribute has no value [like: Clarity: ] thats mean don’t change this. 3. The Names are given by me, So Change it as you want. 🙂 4. Change any Numbers to get the best Effect you are looking for. 5. The White Balance setting is as my Room lights 🙂 So you need to change it. Click Here to Read about Sony Picture Profiles.

Tips Works for Me. 🙂
[NOTE: If you applay any setting to a Film-Simulation then this setting will be applayed only to that Film-Simulation. So I am changing and setting the same to all my Simulation.]

1. View Mode: VIEW MODE button switching between LCD and Electronic viewfinder (EVF).
[My Setting is: Using EVF Only to save the battery life.]
2. Shutter Sound:
3. Release/Focus Priority: In focus mode AF-S or AF-C.
RELEASE: Shutter response is prioritized over focus. Pictures can be taken when the camera is not in Focus.
FOCUS: Focus is prioritized over shutter response. Pictures can be only taken when the camera is in focus.
[My Setting is: FOCUS in Both mode.] NOTE: We Need to Turn the AF+MF to OFF so the ‘in Focus’ Mode will be Active.
4. PRE-AF: [This Option using more Buttery] Option to keep the camera in focus even if you did not pressing the shutter-release.
–> From Menu GoTo AF-MF Then select PRE-AF Set-it to be ON.
I set this to ON for all 7 film-Simulation i use.
5. AF-C Custom SETTING: This option has three attributes:
Tracking Seneitivity: If the object is moving
SpeedTracking Seneitivity: Speed of re-focusing between the objects in the frame.
Zone Area Switching: If you are focusing on an object, and another object enter the frame then, When you want the camera catch the focus?
–>From Menu GoTo AF-MF Then select AF-C Custom SETTING, then select option number 6. My setting Tracking Seneitivity is 4, Speed Tracking Seneitivity is 2, Zone Area Switching is Center.
6. I set the BKT1 Option to Take 2 Frames adding 1 STEP of Aperture. So with each shot i will have two photos one is more lighting.
7. I Notes that if the Drive Dail is on [S] the shots are sharpper then if it is on CL or CH.
8. Clarity value in Recipes: You may notes that if the Clarity > 0 this let’ the camera take time to process the Photos. My Setting is always 0)

9. I set the BKT2 Option to Take 3 Frames each with different film simulation,[My Choises are:Classic Neg, Monochrome, Eterna ].–>From Menu GoTo Shooting Setting then select / Drive setting the BKT2 Setting> go down to Film Simulation and select your 3 choices, then go-Back to BKT2 Setting and from the first [BKT select] go-in and select Film Simulation.
Note.. i fond that the images takes some effects from the FS you select and add some effects for the custom recipe simulation
10. Back Button Focusing: > From Menu GoTo Setup, then select BUTTON/DIAL SETTING, then select SHUTTER AF, then change AF-C to OFF, now Go-Back and select the FUNCTION (fn) SETTING, from there you select any button you want (I select the AF-L) and set-it to AF-ON. DONE.
11. Most of the settings below are with Noise Reduction value more than +2, for indoor or with ISO +32000 I am setting / changing this to 0 [for kids and family photography].
